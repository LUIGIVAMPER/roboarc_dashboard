Daily progress update

Trials with a result per pair, in the format for everyday progress sharing: one block per helper, then all helpers together. Copy a block and paste it.

Run setup

The MANIFEST.md of each helper's latest delivery: GPUs and driver, CPU and memory, software versions, and the runner's settings and concurrency.

Machine types

Resources are allocated by the kind of object a task handles. Measured peaks are the memory and GPU memory peaks the grader records for each trial (verifier/reward.json).

Deliveries

Every bundle in the dataset (<helper>/<batch>/<bundle>/), open pull requests included. Open a row for its MANIFEST.md and the error lines of its batch log.

Errors and reruns

Trials that are not a result (an infrastructure failure: rerun with the same seed), trials without a verdict, trials with a Harbor exception, and trials run more than once. Open a row for the exception and the logs.

Task matrix

Six squares per cell: top row privileged trials 1–3, bottom row standard trials 1–3. Hover for the trial, click to open it.

First frames

The birth frame (cam_high) of each base at its 3 appearance seeds. Privileged and standard share one scene, so 3 frames cover the 6 variants; the 12 IKEA bases allow seed 0 only.

Data: the Hugging Face dataset RoboARC/RoboARC-outputs (public). The delivery format is RoboARC's scripts/send_results.sh.
