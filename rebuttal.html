RoboARC Rebuttal Experiments

Five experiments, E1–E5, on task variants of the released puzzles: 366 trials, every one at appearance seed 0. Each step is sent back to the Hugging Face dataset and checked before the next: the variant checks, the smoke, then the runs, one batch per repeat.

Step 1: variant checks

The latest report of each experiment from <helper>/rebuttal-checks/<UTC time>/ (bash-runners/rebuttal/send_checks.sh): every variant's DIGEST as locked, the reference solution scoring 1 and doing nothing scoring 0, the condition's own check. An experiment's runner starts only after its report passed.

Step 2: smoke

One trial of each variant of each experiment's first task, in the batches rebuttal-smoke-e1 … rebuttal-smoke-e5 (16 trials, not part of the results). Open a trial for its timeline.

Results by condition

Successes over trials with a result, per condition and mode, overall and per repeat. The last rows of each table are the main evaluation's results of the same released tasks at seed 0 with the same harness and model, for reference: its run id names the effort, which may differ from the experiment's.

Task matrix

One row per task, one column per condition and mode, one square per repeat; on the right the main evaluation's released task at seed 0 (standard, privileged). Hover for the trial, click to open its timeline.

Errors and reruns

Trials that are not a result (an infrastructure failure: rerun with the same seed and batch), trials with a Harbor exception, trials run more than once, and trials whose settings do not match the plan (run id, effort, seed, task, condition, mode). Open a row for its timeline.

Deliveries

Every bundle in the dataset (<helper>/<batch>/<bundle>/), open pull requests included, with the trials its batch plans. A later delivery of a batch carries its earlier trials again: each trial counts once, from the latest.

Data: the Hugging Face dataset RoboARC/RoboARC-rebuttal-outputs (public). The delivery format is RoboARC's scripts/send_results.sh; the guide is docs/REBUTTAL_EXPERIMENTS.md.
